Resize, compress and convert images online

Use KriXo image tools to change image dimensions, reduce a photo toward a target KB size, or convert between common formats. The photo and signature resizer can prepare an image for an online form when you know the exact pixel and file-size limits.

Which image tool should you use?

  • Compress image: reduce a JPG, PNG, WebP, GIF or BMP toward a maximum KB size.
  • Resize image: set exact width and height in pixels, with an option to keep the aspect ratio.
  • Convert image: change JPG, PNG, WebP, GIF or BMP into JPG, PNG or WebP.
  • Photo and signature: set the pixel dimensions and KB limit required by a form.
  • Check file requirements: compare a file's size and dimensions with limits you enter.

Check the result before uploading

Compression can reduce image detail, resizing can change proportions if aspect ratio is turned off, and converting a transparent image to JPG places transparent areas on a white background. Always compare the downloaded file with the current official form instructions.
