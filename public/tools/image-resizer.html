Frequently asked questions

Are my files uploaded to a server?

No. This tool uses your browser to read and process the selected file. File contents are not sent to the KriXo backend.

Is this tool free?

Yes. The first version is free to use without an account. Browser memory and device performance may limit very large files.

Will the output meet the portal's requirements?

Not automatically. Enter the exact requirements and inspect the output. Some portals apply additional rules that a generic tool cannot detect.

Resize an image to exact pixel dimensions

Set the width and height you need in pixels to resize a photo, screenshot or graphic. The tool supports common image formats and can keep the original aspect ratio or fit the image inside the dimensions you enter.

  1. Choose the image you want to resize.
  2. Enter the required width and height in pixels.
  3. Keep aspect ratio enabled to avoid stretching, or turn it off only when distortion is acceptable.
  4. Choose an output format, resize and check the downloaded image.

Pixel dimensions and file size are different

Changing width and height does not guarantee a particular KB size. If a form sets both pixel and file-size limits, resize the image first and then use the Image Compressor. Check the final dimensions and KB size with the File Requirements Checker.
