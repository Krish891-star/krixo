Frequently asked questions

Does this tool change my PDF?

No. This is a read-only tool. The file is opened, its properties are read, and nothing is written or downloaded.

What does "encrypted" mean?

An encrypted PDF requires a password to open. Use the Unlock PDF tool to create an unprotected copy (you need to know the password).

What are page dimensions in points?

PDF dimensions are measured in points (pt). One inch equals 72 points. A standard A4 page is 595 × 842 pt; a US Letter page is 612 × 792 pt.
