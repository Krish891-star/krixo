Frequently asked questions

Are my files uploaded to a server?

No. This tool uses your browser to read and process the selected file. File contents are not sent to the KriXo backend.

Is this tool free?

Yes. It is free to use without an account. Browser memory and device performance may limit very large files.

What if the output is not exactly what I expected?

Every conversion is performed by a browser library with known limits. Check the "How it works" panel above, then try a smaller or simpler file if needed.

Convert Excel spreadsheets to PDF

Convert an XLSX, XLS or CSV file into a PDF that is easier to share or print. KriXo reads the workbook sheets and places each sheet into a PDF section; wide sheets use landscape pages automatically.

  1. Choose an XLSX, XLS or CSV file.
  2. Select Excel to PDF and wait while the sheets are prepared.
  3. Download the PDF and check the table layout and page breaks.

Workbook features and limits

The tool supports up to 1,000 rows and 40 columns per sheet. Charts, pivot tables and macros are not rendered. Check the result before sharing, especially when a spreadsheet uses complex formatting. For the reverse direction, use PDF to Excel.
