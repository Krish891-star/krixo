Frequently asked questions

Are my files uploaded to a server?

No. This tool uses your browser to read and process the selected file. File contents are not sent to the KriXo backend.

Why can't I reach a very small target with PNG?

PNG is lossless compression. The file size is determined by the image content. If you need to reach a low KB target, choose JPG or WebP instead.

Will the output meet the portal's requirements?

Not automatically. Enter the exact KB limit your portal specifies and inspect the output. Some portals also check dimensions, so use the File Requirements Checker to verify both.

Compress an image to a target KB size

Use this image compressor to reduce a photo or graphic toward a maximum file size, such as 50 KB, 100 KB or 200 KB. It supports JPG, PNG, WebP, GIF and BMP input and lets you choose JPG, WebP or PNG output.

  1. Select one or more images.
  2. Enter the maximum file size in KB and choose an output format.
  3. Compress the image, preview the result and download it if the quality is acceptable.

Why a target size may not be possible

KriXo tries lower quality settings and can reduce image dimensions when needed. PNG files are lossless and may not shrink enough for very small targets; JPG or WebP may produce a smaller file. Always inspect text, signatures and fine details after compression. Use the File Requirements Checker to compare the result with your upload limits.
