How it works

The browser first tries a normal load-and-save with pdf-lib. If that fails, PDF.js renders each readable page and a fresh PDF is built from those pages. Success depends on how damaged the file is.

Frequently asked questions

Are my files uploaded to a server?

No. This tool uses your browser to read and process the selected file. File contents are not sent to the KriXo backend.

Is this tool free?

Yes. It is free to use without an account. Browser memory and device performance may limit very large files.

What if the output is not exactly what I expected?

Every conversion is performed by a browser library with known limits. Check the "How it works" panel above, then try a smaller or simpler file if needed.
