Frequently asked questions

Are my files uploaded to a server?

No. This tool uses your browser to read and process the selected file. File contents are not sent to the KriXo backend.

Can I extract non-consecutive pages?

Yes. For example, entering 1,3,7-9 produces a 5-page PDF containing pages 1, 3, 7, 8, and 9 of the original.

What is the difference between this and Extract PDF Pages?

Both tools save the pages you choose as one PDF. Split PDF is designed for ranges such as 1-3,7; Extract PDF Pages is designed for picking individual pages. The downloaded result is the same.

Split a PDF by page number or page range

Use the PDF splitter to save selected pages as a new PDF without changing the original document. Enter individual page numbers, ranges, or a combination such as 1-3,7,10-12.

  1. Choose the PDF you want to split.
  2. Enter the page numbers or ranges to keep.
  3. Select Extract pages and wait for the new PDF.
  4. Check the downloaded file's page count and contents.

Split PDF or extract pages?

This tool creates one new PDF containing the selected pages in ascending page order. It does not create a separate file for every page range. To combine pages from several different PDFs, use Merge PDF.
