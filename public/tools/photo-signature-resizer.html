Frequently asked questions

Are my files uploaded to a server?

No. This tool uses your browser to read and process the selected file. File contents are not sent to the KriXo backend.

Is this tool free?

Yes. The first version is free to use without an account. Browser memory and device performance may limit very large files.

Will the output meet the portal's requirements?

Not automatically. Enter the exact requirements and inspect the output. Some portals apply additional rules that a generic tool cannot detect.

Prepare a photo or signature for an online form

Use the photo and signature resizer when a form specifies exact image dimensions in pixels and a maximum file size in KB. Enter the requirements from the current official notice rather than relying on an old preset.

  1. Read the form's latest photo or signature instructions.
  2. Enter the required width, height and maximum KB size.
  3. Choose whether to fit inside the dimensions or crop to the exact size.
  4. Prepare the image, then check its dimensions and file size before upload.

What this tool does not change

This tool does not replace the background or retouch faces. If you need a different crop, prepare the crop first. Use the File Requirements Checker to verify the final file against the limits you entered.
