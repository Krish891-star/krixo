How it works

PDF.js opens the document with the password you enter, renders the pages, and KriXo builds a new PDF without the open password.

No sign-up needed for this tool.
The password is used only in your browser.
The unlocked copy is generated locally.

Before you download

  • You must know the document password.
  • Only use this on files you are allowed to modify.
  • The rebuilt PDF is image-based: selectable text, links and form fields are not preserved.

Frequently asked questions

Are my files uploaded to a server?

No. The PDF is opened and processed in your browser. File contents are not sent to the KriXo backend.

Is this tool free?

Yes. It is free to use without an account. Browser memory and device performance may limit very large files.

What if the output is not exactly what I expected?

Browser-based processing has known limits. Check the “How it works” panel above, then try a smaller or simpler file if needed.
