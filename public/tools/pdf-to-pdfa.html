How it works

The PDF is reopened, form fields are flattened where supported, embedded scripts and attachments are removed, archival metadata is set and the file is rewritten with object streams. True PDF/A certification requires Ghostscript or veraPDF on a server; this browser tool deliberately does not claim compliance.

No sign-up needed for this tool.

Before you download

  • Always validate the result with veraPDF before submitting it to an archive.
  • Interactive forms are flattened where the browser library supports it.

Frequently asked questions

Are my files uploaded to a server?

No. This tool uses your browser to read and process the selected file. File contents are not sent to the KriXo backend.

Is this tool free?

Yes. It is free to use without an account. Browser memory and device performance may limit very large files.

What if the output is not exactly what I expected?

Every conversion is performed by a browser library with known limits. Check the "How it works" panel above, then try a smaller or simpler file if needed.
