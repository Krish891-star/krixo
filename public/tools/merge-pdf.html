Frequently asked questions

Can I add more files after the first selection?

Yes. Use the Choose PDFs button or drop more files onto the dropzone. New files are added to the end of the list and you can drag them to any position.

Is there a file size limit?

Up to 150 MB total and 45 MB per individual file. Browser memory may impose lower limits on older devices.

Can I merge password-protected PDFs?

No. Use the Unlock PDF tool first, then come back and merge the unlocked copies.

Combine multiple PDF files into one document

A PDF merger joins separate PDF files into one document. KriXo lets you add multiple PDFs, change their order before merging and download a new combined file. The original files remain unchanged.

  1. Select the PDF files you want to combine.
  2. Review the file list and drag each file into the required order.
  3. Remove any file you do not need, then choose Merge PDFs.
  4. Download and check the merged PDF.

Before merging PDFs

You can add up to 30 PDFs, subject to the per-file and total-size limits shown in the tool. Password-protected PDFs must be unlocked first. If you only need selected pages from one file, use Split PDF or Extract PDF Pages.
