How it works

Each selected page is rendered, converted to greyscale pixel data, and embedded into a new PDF at the original page size.

No sign-up needed for this tool.
Conversion happens locally in your browser.
Useful for black-and-white printing.

Before you download

  • Selectable text is not preserved.
  • Very fine coloured lines may become hard to read.
  • Higher render quality keeps more detail.

Frequently asked questions

Are my files uploaded to a server?

No. The PDF is opened and processed in your browser. File contents are not sent to the KriXo backend.

Is this tool free?

Yes. It is free to use without an account. Browser memory and device performance may limit very large files.

What if the output is not exactly what I expected?

Browser-based processing has known limits. Check the “How it works” panel above, then try a smaller or simpler file if needed.
