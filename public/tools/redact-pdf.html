How it works

The selected pages are rendered, the marked rectangles are painted black, and a fresh image-based PDF is created from those pages.

No sign-up needed for this tool.
Redaction happens locally in your browser.
The covered content is not present in the downloaded PDF.

Before you download

  • Redaction works on rendered pages, so selectable text is not preserved.
  • Check the output carefully before sharing it.
  • Boxes use PDF points from the bottom-left corner (72 pt = 1 inch).

Frequently asked questions

Are my files uploaded to a server?

No. The PDF is opened and processed in your browser. File contents are not sent to the KriXo backend.

Is this tool free?

Yes. It is free to use without an account. Browser memory and device performance may limit very large files.

What if the output is not exactly what I expected?

Browser-based processing has known limits. Check the “How it works” panel above, then try a smaller or simpler file if needed.
