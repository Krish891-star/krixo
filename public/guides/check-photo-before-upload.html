Check a photo before uploading it.

A quick checklist to avoid common file upload errors.

  1. Read the latest official notice. Do not assume last year's photo dimensions or size range still apply.
  2. Check the format. Confirm whether the portal accepts JPG, JPEG, PNG or another format.
  3. Check the KB range. Some forms specify both a minimum and a maximum size.
  4. Check pixel dimensions. A file can be small enough but still have the wrong width or height.
  5. Check the visible photo. Make sure the face, signature or text remains clear after compression.
  6. Keep the original. Save a copy before resizing or compressing.
