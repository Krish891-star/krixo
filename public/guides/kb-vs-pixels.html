KB and pixels: what is the difference?

Two different measurements. Both can matter when you upload a photo.

File size (KB)

KB describes how much storage the image file uses. A 90 KB image takes less storage than a 900 KB image. Compression usually reduces this number by changing image quality, dimensions or both.

Dimensions (pixels)

Pixels describe the width and height of the image. A 600 × 800 pixel image is 600 pixels wide and 800 pixels tall. Resizing changes the number of pixels.

Why a form may check both

A portal may require a photo to be within a certain KB range and within specific pixel dimensions. Meeting only one requirement is not enough. Read the current official instructions, enter both limits in the File Requirements Checker, and inspect the output.
