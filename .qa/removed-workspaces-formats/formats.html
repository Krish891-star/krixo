Format matrix

What KriXo really supports.

We would rather tell you the limits upfront than show a successful download with a broken result. Everything below reflects the current browser-only build.

Privacy note: your input files are not uploaded to a processing server. Page scripts, fonts, WASM modules and OCR language data may still be downloaded by your browser.
FormatSupportWhat that means
PDFFully supportedMerge, split, rotate, crop, reorganise, stamp, compress, inspect and export pages.
JPG / PNG / WebPFully supportedImage input and output for compress, resize, convert and images-to-PDF.
GIF / BMPPartialAccepted as image input; canvas conversion uses the first frame only.
DOCXPartialDOCX to PDF uses mammoth; PDF to DOCX is a text-based editable reconstruction.
XLSX / XLS / CSVPartialSpreadsheets to PDF use SheetJS; PDF to XLSX uses text and column heuristics.
PPTXPartialPPTX to PDF rebuilds slides from OOXML; PDF to PPTX creates positioned text/image slides.
HTML / TXT / MarkdownSupportedPaste or upload HTML/TXT for PDF; PDF to Markdown exports selectable text.
Tesseract OCR languagesPartialEnglish only, downloads language data on first use, limited to 20 pages per run.
DOC / ODT / RTF / ODS / PPT / ODPNot supportedNo native office engine is available in this browser build. Convert to DOCX/XLSX/PPTX first.
AVIF / TIFF / HEIC / SVGNot supportedNot accepted as reliable conversion paths. Convert to JPG or PNG first.
Encrypted PDFsPartialUnlock requires a password you already know; most other tools need an unlocked PDF.
Certified PDF/A / cryptographic signaturesNot supportedPDF/A Preparation is metadata cleanup only; signatures are visual images.
