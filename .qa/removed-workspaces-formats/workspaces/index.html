Workspaces

Work around the job, not the file type.

Each workspace groups the tools that belong together. Every tool keeps its own direct URL and stays visible in the full tool list.

PDF Workspace

See pages as thumbnails, then split, reorder, extract, delete, rotate or crop them. Manual page numbers stay available.

PDF Editor

Stamp text or an image, add a visual signature, watermark pages, number them, or flatten annotations. These edits are visual, not a full layout editor.

Image Studio

Compress, resize or convert JPG, PNG, WebP, GIF and BMP. Process up to 20 images in one batch and download them as a ZIP.

File Converter

Convert the formats this browser build can actually read. Layout is reconstructed, not identical to Word, Excel or PowerPoint.

PDF Security

Password-protect by rebuilding pages, unlock a PDF you can already open, cover redaction areas, and edit metadata. Protection here is not certificate signing.

PDF Intelligence

Read document facts, compare selectable text, and add an English OCR text layer on scanned pages. This is not an AI summary.

PDF Optimizer

Shrink a PDF by rasterising pages, repair structure, convert to grayscale, or prepare PDF/A metadata. Compression makes text non-selectable.

Merge & Combine

Combine PDFs or images in the order you set. Drag, move or remove files, then download one document.
